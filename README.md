# Blinkit Grocery Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing Blinkit grocery sales data using Microsoft Power BI. An interactive dashboard was developed to understand sales performance, customer preferences, product categories, and outlet performance through meaningful visualizations and KPIs.

## Objectives
- Analyze overall grocery sales performance.
- Understand sales distribution across item categories.
- Compare outlet performance by size, location, and type.
- Identify customer preferences through item ratings.
- Present key business insights using an interactive dashboard.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

## Key Performance Indicators (KPIs)
- Total Sales: $1.20M
- Average Sales: $140.99
- Number of Items: 8,523
- Average Rating: 3.9

## Dashboard Features
1. **KPI Cards:** Displays total sales, average sales, number of items, and average rating.
2. **Sales Trend Analysis:** Shows outlet establishment year-wise sales.
3. **Item Analysis:** Analyzes sales across different grocery item categories.
4. **Outlet Analysis:** Compares sales based on outlet size, location, and type.
5. **Interactive Filters:** Enables filtering by outlet location, outlet size, and item fat content.
6. **Data Visualization:** Uses bar charts, donut charts, and tables to present business insights.

## Key Learnings
- Data cleaning and transformation using Power Query.
- Creating calculated measures using DAX.
- Designing interactive Power BI dashboards.
- Analyzing business KPIs and sales trends.
- Converting raw data into meaningful business insights.
